# MIRACLE ARENA · Expo SDK 57

Nuovo progetto mobile salvato nel repository GitHub per evitare di perdere nuovamente il sorgente.

## Target
- Expo SDK 57.0.17+
- React Native 0.86.3
- React 19.2.3
- iPhone 13 / iOS 16.4+
- Orientamento landscape

## Avvio
1. `cd expo57`
2. `npm install`
3. `npx expo-doctor`
4. `npx expo start`
5. Aprire il QR con Expo Go aggiornato.

## Stato demo
Vertical slice interattiva senza permessi speciali: movimento, attacco, combo, colpo potente, schivata, energia, HP, KO e restart.

## Regola di progetto
Il sorgente resta sempre in GitHub. Nessuna versione viene dichiarata pronta per iPhone finché non supera `expo-doctor` e un avvio reale in Expo Go.
